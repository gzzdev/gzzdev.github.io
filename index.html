1. Función principal: process_inbox

Coordina el recorrido. Por cada mensaje llama a las funciones auxiliares, omite paquetes vacíos y cuenta los trabajos publicados. 

async def process_inbox():
    messages = await get_unseen_messages()
    enqueued = 0
    for message in messages:
        files = await extract_attachments(message)
        files = normalize_files(files)
        files = validate_group_and_deduplicate(files)
        if not files:
            continue
        package = prepare_package(message, files)
        await publish_document_job(package)
        enqueued += 1
    return enqueued
Orden: mensajes → adjuntos → validación → paquete → cola.
2. Buscar mensajes pendientes

Consulta solo mensajes no procesados para no volver a encolar los que ya se atendieron. 

async def get_unseen_messages():
    return await mail.search(
        folder="INBOX",
        unread=True,
        without_label="documents-enqueued"
    )
Se llama desde: process_inbox()
3. Extraer adjuntos

Recorre los adjuntos del mensaje y conserva los archivos que pueden entrar al flujo documental. 

async def extract_attachments(message):
    attachments = await mail.get_attachments(message.id)
    return [item for item in attachments
            if item.has_content]
Se llama después de: get_unseen_messages()
4. Normalizar archivos

Unifica nombres y tipos para que archivos equivalentes se procesen de forma consistente. 

def normalize_files(files):
    return [file.with_metadata(
        name=clean_filename(file.name),
        content_type=detect_content_type(file)
    ) for file in files]
Se llama después de: extract_attachments()
5. Validar, agrupar y deduplicar

Descarta archivos inválidos, agrupa los relacionados y elimina duplicados usando una huella del contenido. 

def validate_group_and_deduplicate(files):
    valid = [file for file in files
             if allowed_type(file.content_type)
             and file.size < MAX_FILE_SIZE]
    unique = {sha256(file.content): file for file in valid}
    return group_by_document(list(unique.values()))
Se llama después de: normalize_files()
6. Preparar el paquete

Construye el payload que recibirá el worker: origen del mensaje, archivos y metadatos para trazabilidad. 

def prepare_package(message, files):
    return {
        "source_message_id": message.id,
        "sender": message.sender,
        "files": [file.to_payload() for file in files],
        "idempotency_key": make_key(message.id, files)
    }
Se llama después de: validate_group_and_deduplicate()
7. Publicar en la cola

Envía el paquete al worker. La clave de idempotencia ayuda a evitar trabajos duplicados si el correo vuelve a consultarse. 

async def publish_document_job(package):
    await queue.publish(
        topic="documents.process",
        message=package,
        deduplication_key=package["idempotency_key"]
    )
Aquí termina el encolado. El worker consume este mensaje para procesar los documentos.
